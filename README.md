# AI Supply Chain Disruption Response Agent

Hackathon MVP:
Supplier -> Inventory -> Demand -> Logistics -> Risk -> Impact -> Alternative -> Decision

## Run
npm install
npm run dev

Open http://localhost:3000

The MVP uses deterministic simulated agent logic, so no API key is required.
An optional Gemini key can be added later for natural-language explanations.

## Demo
Supplier A delayed 5 days + inventory 2 days + high demand + logistics delay.
The agent correlates the signals, assesses risk, compares alternatives, and recommends a mitigation action with human approval.
